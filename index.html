Why it's different

Most tools take over your terminal. termling stays out of the way.

It never wraps, replaces, or proxies your shell. A tiny fire-and-forget hook whispers “a command started / finished” to a creature in the next pane — and that's the whole contract.

Beside, not instead

Your terminal, prompt, completions, aliases — untouched. termling draws no shell of its own; it just reacts next door in tmux, iTerm2, kitty, or WezTerm.

zsh · bash · fish

Zero network by default

The default binary makes no network calls, ever — no telemetry, no phone-home. Just two dependencies; the socket, games, and themes are all hand-rolled.

opt-in online mode, off by default

A buddy that learns you

A local, non-LLM “buddy brain” watches which tools you run and talks back — greeting a new tool, cheering a clean build, noticing when something ran slow for you.

on-device · a few KB of state

Moods, XP & an arcade

Commands shift the creature's mood and earn XP; a success streak levels you up. When a build drags, press g for a pocket arcade of mini-games.

A dashboard, under the buddy

Press d for a sidebar of panes split under the creature: git status, system vitals, a clock — plus opt-in weather, stocks, news, and a Claude tip.

Install

One line, then wire up the hook.

Prebuilt binaries for Apple-Silicon macOS and x86-64 Linux — a default (zero-network) build and an -online build. Any platform with Rust can install from source.

1 · get termling

No sudo — installs to ~/.local/bin.

# default (zero-network) build
curl -fsSL https://termling.github.io/install.sh | sh

# …or the networked build
curl -fsSL https://termling.github.io/install.sh \
  | TERMLING_INSTALL_ONLINE=1 sh

# …or from source (any platform)
cargo install --git https://github.com/termling/termling

2 · wire up your shell

Additive — it only registers command-lifecycle callbacks.

eval "$(termling init zsh)"     # ~/.zshrc
eval "$(termling init bash)"    # ~/.bashrc
termling init fish | source     # fish

# then open a new window — the
# companion auto-spawns beside it.

Homebrew and cargo install termling land with the first published registry build · online panes stay inert until you set TERMLING_ONLINE=1.
